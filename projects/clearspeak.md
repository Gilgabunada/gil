# CLEARSPEAK

## Overview
CLEARSPEAK is an AI-powered speech recognition system designed to transcribe and assist people with cleft lip and palate (CLP) speech impediments. Built as a portable, offline-capable device, it runs on Raspberry Pi with Arduino integration for GPIO control.

## Problem Statement
Individuals with cleft lip and palate often face challenges with speech intelligibility. CLEARSPEAK leverages advanced AI to transcribe their speech in real-time, improving communication accessibility and confidence.

## Key Features
- **Offline Speech Recognition**: Uses OpenAI's Whisper base model for local speech-to-text processing
- **Real-time Transcription**: Low-latency speech recognition suitable for live communication
- **Multi-Voice Selection**: Choose from 3 different voice options for audio feedback
- **Portable & Rechargeable**: Battery-powered design with charging capability for on-the-go use
- **HDMI Display Support**: Connect to external monitors for flexible display options based on usage context
- **Hardware Integration**: Raspberry Pi + Arduino for GPIO control and real-time processing
- **Zero Internet Dependency**: Fully runs locally — no cloud connectivity required
