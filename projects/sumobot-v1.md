# Sumobot V1 (First Generation)

## Overview
The original sumobot project developed during 2nd year of college. This was the first autonomous sumo robot, built to compete against senior students within the university. Despite challenges in sensor integration and motor control, it demonstrated early autonomous robotics capabilities.

## Project Type
**Personal Project** — 2nd Year College (2024-2025)
- **Competition**: University internal sumo robot competition
- **Opponents**: Competed against robots built by senior students
- **Status**: Fully autonomous operation

## Development Journey
This project was a significant learning experience, tackling the complexities of multi-sensor integration and autonomous motor control for the first time. The development process involved troubleshooting sensor readings, calibrating motor responses, and optimizing navigation logic.

## Key Features
- **Fully Autonomous**: No manual control — AI-driven decision making
- **Multi-Sensor Integration**: Multiple sensors working in coordination
- **Ultrasonic Sensors**: For opponent detection and navigation
- **IR Sensors**: Ground-based infrared sensors to detect dohyo (ring) boundaries by reading ground reflection
- **Ring Boundary Detection**: IR reflection sensing keeps robot inside the dohyo during matches
- **Motor Control System**: Autonomous motor management for competitive advantage
- **Real-time Navigation**: Sensor-based movement and obstacle detection
- **Competition-Ready**: Built to compete against university teams

## Technical Stack
**Languages & Frameworks:**
- C/C++ (Arduino firmware)

**Hardware:**
- Arduino microcontroller
- Multiple DC motors with gear reduction
- Multiple ultrasonic sensors
- IR sensors (infrared reflectance sensors for dohyo edge detection)
- Motor drivers & power management
- Custom chassis

**Challenges Overcome:**
- Sensor noise filtering and calibration
- Multi-motor synchronization
- Autonomous decision-making logic
- Real-time sensor input processing
- Power management under load

## Learning Outcomes
This project was instrumental in understanding autonomous robotics fundamentals, sensor integration complexity, and the iterative design process required for competitive robotics.
