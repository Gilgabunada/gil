# Temperature & Humidity Sensor PCB

## Overview
A custom-designed printed circuit board (PCB) for a temperature and humidity sensor. This was the first PCB designed and fabricated from scratch, demonstrating hands-on experience with circuit design, PCB manufacturing, and soldering techniques.

## Project Type
**Personal DIY Project** — First Custom PCB (2023)

## Design & Fabrication Process
This project showcases the complete PCB development workflow:

1. **Circuit Design**: Schematic design for temperature and humidity sensing
2. **PCB Layout**: Used EasyEDA for professional circuit board design
3. **PCB Manufacturing**: 
   - Laser printer for toner transfer printing
   - Hot iron method for ink transfer onto PCB copper layer
   - Chemical etching to remove unwanted copper and create circuit traces
4. **Component Assembly**: Soldering electronic components onto the finished PCB

## Key Features
- **Temperature Sensing**: Accurate temperature measurement
- **Humidity Sensing**: Real-time humidity level detection
- **Custom PCB Design**: Optimized layout for compact form factor
- **DIY Fabrication**: Toner transfer and chemical etching process
- **Single-Sided or Double-Sided Design**: Efficient trace routing
