# LAN Cable Termination with RJ45

## Overview
A practical networking project from the Cisco curriculum focused on proper Ethernet cable termination techniques. This foundational skill demonstrates understanding of network infrastructure standards and best practices for physical layer connectivity.

## Project Type
**School Networking Project** — Cisco Networking Course

## Learning Objective
Master proper LAN cable preparation, stripping, and RJ45 connector termination according to industry standards (EIA/TIA 568A and 568B).

## Key Skills Learned
- **Cable Preparation**: Stripping and organizing twisted pair wires
- **Wire Sequencing**: Following correct color order (EIA/TIA 568A or 568B standards)
- **RJ45 Crimping**: Proper connector insertion and crimping pressure
- **Connector Standards**: Understanding when to use 568A vs 568B configurations
- **Cable Testing**: Verification of proper connectivity and pin alignment
- **Quality Control**: Identifying and preventing common termination errors

## Technical Specifications
**Standards Covered:**
- EIA/TIA 568A wiring order
- EIA/TIA 568B wiring order
- Straight-through cables (both ends same standard)
- Crossover cables (different standards)

**Tools & Equipment:**
- Cat5e or Cat6 Ethernet cable
- RJ45 connectors
- Cable stripper/crimper tool
- Ethernet cable tester
- Wire cutters

**Cable Categories:**
- Cat5e (100 Mbps)
- Cat6 (1 Gbps)
- Cat6a (10 Gbps)

## Best Practices Demonstrated
- Minimum bend radius to prevent signal degradation
- Proper untwisting length (no more than ½ inch)
- Consistent wire alignment within connector
- Even crimping pressure for reliable connection
- Testing each termination for continuity
