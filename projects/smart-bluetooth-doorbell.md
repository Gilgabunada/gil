# Smart Bluetooth Doorbell

## Overview
An intelligent doorbell system that connects via Bluetooth to a homeowner's smartphone. This IoT device enables remote doorbell management and visitor notifications, allowing homeowners to control doorbell behavior and status from anywhere using their phone.

## Project Type
**Personal IoT Project** — Smart Home Integration

## Purpose
Modernizes traditional doorbell functionality by adding remote control and smart notifications, giving homeowners flexibility in managing visitor access and setting availability status.

## Key Features
- **Bluetooth Connectivity**: Direct wireless connection to smartphone via Bluetooth
- **Remote Control**: Manage doorbell settings from mobile phone app
- **Availability Status**: Set doorbell modes such as:
  - "Nobody Home" mode — informs visitors that no one is available
  - "Do Not Disturb" — silences doorbell notifications
  - "Active" — normal doorbell operation
- **Real-Time Notifications**: Instant alerts to smartphone when doorbell is pressed
- **Visitor Awareness**: Displays customizable messages to visitors based on home status
- **Portable Control**: Homeowners can manage settings from anywhere with Bluetooth range
