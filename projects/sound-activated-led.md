# Sound-Activated LED Controller

## Overview
A sound-reactive LED control system that uses a microphone to detect clapping patterns. This Arduino-based project demonstrates audio input processing and real-time LED control through pattern recognition.

## Project Type
**School Midterm Project** — 2nd Year College  
Course: Arduino & Embedded Systems

## Concept
The system uses sound input from a microphone to trigger different LED responses based on clap patterns, showcasing creative use of sensors and real-time signal processing.

## Key Features
- **Clap Detection**: Microphone-based sound trigger system
- **Pattern Recognition**:
  - 1 clap → Red LED lights up
  - 2 claps → Blue LED lights up
  - Multiple claps → RGB LED blinks in sequence
- **Real-time Response**: Immediate LED feedback based on detected patterns
- **RGB Control**: Full color support for visual feedback
