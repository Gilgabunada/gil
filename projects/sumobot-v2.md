# Sumobot V2 (2nd Generation)

## Overview
Sumobot is a competitive robotics project designed for sumo robot competitions. This autonomous robot competes against other university teams, engineered for maximum pushing power and intelligent obstacle detection.

## Project Type
**Personal Project** — Ongoing competitive robotics development
- **Purpose**: Compete in sumo robot competitions across multiple universities
- **Competition Type**: Autonomous sumo wrestling (robot-vs-robot battles)
- **Design Focus**: Durability, speed, and intelligent sensor-based navigation

## Key Features
- **6 Low-Gear Motors**: High torque configuration for powerful pushing capability
- **3 Ultrasonic Sensors**: 
  - 2 front sensors for opponent detection and obstacle avoidance
  - 1 rear sensor for ring edge detection and reverse navigation
- **IR Sensors**: Ground-based infrared sensors to detect dohyo (ring) boundaries by reading ground reflection
- **Autonomous Navigation**: Sensor-driven decision making for competitive advantages
- **Ring Boundary Detection**: IR reflection sensing keeps robot inside the dohyo during matches
- **Compact Design**: Optimized for agility within competition ring constraints
- **Durable Build**: Built to withstand impacts and collisions during sumo matches

## Technical Stack
**Languages & Frameworks:**
- C/C++ (Arduino firmware)

**Hardware:**
- Arduino microcontroller
- 6 low-gear DC motors
- 3 ultrasonic sensors (HC-SR04 or similar)
- IR sensors (infrared reflectance sensors for dohyo edge detection)
- Motor drivers for power management
- Custom chassis design

**Tools:**
- Arduino IDE
- CAD for chassis design

## Competition Performance
Successfully competes against teams from other universities, demonstrating effective sensor integration and autonomous decision-making.
